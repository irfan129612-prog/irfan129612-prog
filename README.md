## 🧪 Hands-On Lab Method

```text
01  Define the objective and expected outcome
 ↓
02  Record environment, tools and prerequisites
 ↓
03  Implement the task with reproducible commands or code
 ↓
04  Capture outputs, screenshots and troubleshooting notes
 ↓
05  Summarize findings, limitations and lessons learned
```

<details>
<summary><b>📂 What a well-documented lab should contain (expand)</b></summary>

```text
lab-XX-topic/
├── README.md              # objective, environment, steps and findings
├── src/                   # scripts or configuration (when applicable)
├── screenshots/           # sanitized evidence (when available)
└── sample-data/           # safe, non-sensitive example data
```

Each repository may use a different structure based on its actual lab materials. Published documentation should reflect what was performed and verified; planned exercises are not represented as completed work.

</details>
