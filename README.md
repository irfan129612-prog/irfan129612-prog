- 🐍 **Programming:** Python fundamentals, scripting, data handling and automation
- 📊 **Analytics:** Data cleaning, visualization, exploratory analysis
- 🎯 **Direction:** Data analytics and security-monitoring roles, with a focus on practical, well-documented work
